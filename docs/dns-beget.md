# DNS в Beget

[USER ACTION] В панели Beget открыть управление DNS зоны **mrloic.ru**.
Создать следующие A-записи; если поле имени требует FQDN, использовать полный адрес справа.

| Тип | Имя в зоне | Полное имя | Значение | Назначение |
|---|---|---|---|---|
| A | hub | hub.mrloic.ru | `<PUBLIC_IPV4>` | Приложение и Socket.IO |
| A | rtc | rtc.mrloic.ru | `<PUBLIC_IPV4>` | Защищённый шлюз сигнализации LiveKit |
| A | turn | turn.mrloic.ru | `<PUBLIC_IPV4>` | TURN/TLS |

Подставить адрес самостоятельно только в панели и локальном игнорируемом `.env.production`.
В репозиторий и переписку адрес не нужен. TTL при первом запуске — 300 секунд,
если панель позволяет. Не использовать HTTP-переадресацию вместо DNS.

Не менять корень mrloic.ru, MX, TXT, SPF, DKIM и чужие поддомены. Если именно у этих
трёх имён есть конфликтующие A/AAAA/CNAME, сначала выяснить их назначение.
Не добавлять AAAA без отдельно проверенного IPv6-маршрута и firewall.
Если действующие CAA ограничивают выдачу сертификатов, проверить разрешение
Let's Encrypt отдельно; не удалять ограничения вслепую.

Проверка (Ubuntu с установленным `dig`, иначе `getent ahostsv4`):

```bash
dig +short A hub.mrloic.ru
dig +short A rtc.mrloic.ru
dig +short A turn.mrloic.ru
```

Сверить локально, не вставлять реальные адреса в Git. Дождаться обновления DNS
перед запуском production, чтобы не тратить лимиты ACME.
